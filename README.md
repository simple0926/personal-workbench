# 个人工作台 / Personal Workbench

`personal-workbench` · v0.1.0 · [GitHub Releases](https://github.com/simple0926/personal-workbench/releases) · [发行说明 / Release notes](RELEASE_NOTES.md)

## 中文

把复杂任务组织成四层：决定做什么、选择专业方法、严谨执行、管理和传播成果。

适合需要多个 Skill 配合、交接和验证的任务。提供能力注册表、分层路由、任务合同、交接卡、失败回流及发布授权检查。可选能力按运行环境识别。

1. 从 [GitHub Releases](https://github.com/simple0926/personal-workbench/releases/tag/v0.1.0) 的附件下载 `personal-workbench-v0.1.0.zip`。
2. 解压后把 `personal-workbench/` 文件夹复制到 `~/.codex/skills/`。更新前先备份你自行改过的文件。
3. 在 Codex 里输入 `$personal-workbench`，附上你的目标、已有材料和交付要求。

平台实测仍取决于具体任务、设备与已连接工具。各专业 Skill 可单独安装。

## English

Organizes complex tasks into four layers: decision, domain methods, execution, and asset management and distribution.

Use it for work that needs multiple skills, handoffs, and verification. It includes a capability registry, routing, task contracts, handoffs, failure routing, and publication authorization checks. Optional capabilities are resolved at runtime.

1. Download the attached `personal-workbench-v0.1.0.zip` from [GitHub Releases](https://github.com/simple0926/personal-workbench/releases/tag/v0.1.0).
2. Extract and copy the `personal-workbench/` folder to `~/.codex/skills/`. Back up any local customizations before updating.
3. In Codex, invoke `$personal-workbench` with your goal, available inputs, and expected deliverables.

Platform verification depends on the task, devices, and connected tools. Domain skills can be installed independently.
