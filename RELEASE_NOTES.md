# 个人工作台 / Personal Workbench v0.1.0

## 中文

首个公开版。包含注册表、Skill 清单差异和运行记录校验脚本，以及系统级回归用例。覆盖简单任务、跨域、缺失依赖、失败回流和未授权发布。

平台实测仍取决于具体任务、设备与已连接工具。各专业 Skill 可单独安装。

请选择 Release 附件里的 `personal-workbench-v0.1.0.zip` 安装。

## English

Initial public release. Includes validators for the registry, skill inventory changes, and execution records, plus system regressions for simple tasks, cross-domain work, missing dependencies, failure routing, and unauthorized publishing.

Platform verification depends on the task, devices, and connected tools. Domain skills can be installed independently.

Install using the attached `personal-workbench-v0.1.0.zip` from the release.
